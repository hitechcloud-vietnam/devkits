# Document drafting with source discipline

## Before writing
- Establish purpose, audience, language, output format (.docx, .pdf, .xlsx, Markdown) and jurisdiction for legal/tax/HR content.
- Locate existing material first (templates, prior versions, company records). Read the content; do not rely on file names.
- Separate **verified facts** (with their source) from **assumptions** and **recommendations**. Ask one focused question when a missing fact would change the document materially.

## Drafting
- Reuse established company details only when verified in a source document; leave clearly marked placeholders (`[CẦN BỔ SUNG: ...]`) otherwise.
- Follow the structure and terminology of the organisation's existing documents.
- For time-sensitive matters (laws, decrees, rates, prices), check current official sources and cite them with dates.
- Never invent signatures, approvals, registration numbers, citations or evidence.
- Write new files to an output folder; never overwrite source documents.

## Quality check (run every time)
1. Every factual claim traceable to a source or marked as an assumption.
2. Names, dates, amounts and identifiers consistent throughout.
3. Legal references current and correctly cited; jurisdiction stated.
4. Placeholders listed at the end for the user to complete.
5. Format matches the requested output and renders correctly.
6. High-impact legal, tax, accounting or compliance content flagged for qualified review.

## Output
The document, plus a short note: sources used, assumptions, open placeholders, and recommended reviews.
